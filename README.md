# SynkTimer

A real-time collaborative timer that stays perfectly in sync between two (or more) users.

## Features
- Real-time synchronization using Firebase Realtime Database
- Start, Pause, Resume, Reset controls
- Responsive UI built with HTML, CSS, and JavaScript
- Works across devices — share the timer with a friend
- Ideal for study sessions, workouts, online games, or remote collaboration

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Realtime Backend:** Firebase Realtime Database

## Project Structure
├── index.html # Main HTML file
├── style.css # Styling for the app
├── script.js # Timer + Firebase logic
